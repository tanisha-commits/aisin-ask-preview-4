## How the two designs coexist without being redesigned

- `src/preview-1/` and `src/preview-2/` hold the **original, unmodified** HTML/CSS/JS of each preview
  (Preview 1 from this repo's source, `tanisha-commits/aisin-ask-preview@24ba5d8`; Preview 2 from its live Vercel deployment).
- `tools/scope-css.js` prefixes every rule of each original stylesheet with `.p1` / `.p2` → `p1.css`, `p2.css`.
  Each section sits in a matching wrapper, so it gets exactly its original styling and the two class systems don't collide.
- `tools/build.py` cuts each section **verbatim** out of the original HTML and assembles `index.html`. It also builds
  `p1.js` / `p2.js` (the original scripts, wrapped and with their DOM queries scoped to `.p1` / `.p2`).
  Every edit it makes is listed and asserted in the script:
  - header: removed both "Downloads" links; "Support" → `#contact`
  - links pointing at sections that aren't in Preview 4 were re-pointed: `#resources`/`#support`/`#news` → `#updates`, `#trust` → `#about`, `#audiences` → `#contact`
  - Preview 2 footer logo uses `assets/aisin-ask-logo-transparent-p2.png` (Preview 2's file, which differs from Preview 1's file of the same name)
- `p4.css` / `p4.js` contain only the new Global network section and the enquiry widget (plus a header fix so the
  Preview 1 header stays sticky and its mobile "Enquire" button still shows after "Downloads" was removed).

Rebuild after changing anything in `src/` or `partials/`:

```bash
npm install
npm run build
npm run serve   # http://127.0.0.1:4174/
```

## Global network data

`assets/global-network/data.js` is generated by `tools/global-network/` from
https://www.aisin.com/en/profile/global/ (as of October 2026): 186 group companies, 120 locations, 23 countries.
Markers are placed at city level using the coordinate table in `tools/global-network/cities.js`.
Three listings on the source page have no address (AAC Leasing, AISIN Reinsurance America, PT. ATP Bio Indonesia);
they appear in search but have no marker. Land outlines: Natural Earth via `world-atlas`.

The forms are preview-only and do not transmit data.
